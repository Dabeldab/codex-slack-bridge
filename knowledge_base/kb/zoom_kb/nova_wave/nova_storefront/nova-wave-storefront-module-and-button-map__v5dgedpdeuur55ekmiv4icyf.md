Only use exact wording when it is an actual Nova menu, button, report, field label, device name, payment gateway name, or product feature label.

Use this article when a customer asks where something is in Nova Wave Storefront, what a button does, or how to navigate the Storefront modules.

Main Storefront module buttons
- Sales: opens the main sales portal where products are searched, added to the cart, and checked out.
- Inventory: opens the inventory screen.
- Reports: opens Storefront reports.
- Gift Card: opens the Create Gift Card workflow.
- Cash Drawer: opens Cash Drawer options. This can require a regional-manager-level login or a user with the correct permission. If access is denied, explain that the user does not have access to open the drawer.
- CRM: opens Customer Details/customer management.
- Chat: opens the Storefront chat panel.
- Layaways: opens the Update a Layaway search dialog.
- Quotes: opens the Quote search dialog. Quote access can be permission-gated.
- Competition: opens Competitions.
- My Report: opens the user's personal report screen.
- Appointments: opens the appointment calendar.

Sales portal controls
- Search products: search or scan products by name, barcode, or available product search terms.
- Category buttons: filter the product list by category.
- Display Settings: opens display options for the product grid/list.
- Show Images: toggles product images.
- Show Barcode: toggles barcode display.
- List View: switches between card-style product display and list/table-style display.
- Cart icon on a product card or Add To Cart in list view: adds that product to the cart or opens the product edit drawer when more detail is needed.
- Product edit drawer: shows Exchange, Discount, Price Per Item, Quantity, Subtotal, and Add to Cart or Update Cart.
- Exchange: marks the selected product as an exchange item. Existing exchange items cannot be edited from the cart.
- Discount: opens Add Discount for a product-level discount.
- Price Per Item: editable only when the product is negotiable. Changing below minimum or above suggested price may require manager approval.
- Quantity: sets how many units are added.
- Subtotal: read-only calculated subtotal for the product selection.
- Add to Cart: adds the selected product to the cart.
- Update Cart: saves edits to an existing cart line.

Cart panel controls
- Clear Cart: removes the cart contents and resets the current invoice.
- Product row: click the product details in the cart to reopen the edit drawer.
- Delete/trash icon on a cart row: removes that cart line.
- Subtotal, Tax1 or the configured tax name, tax2 if applicable, Discount, Total: calculated cart totals.
- Pay / [Amount]: opens checkout.
- Freeze sale behavior: Storefront can freeze up to five sale tabs. If the customer sees a warning, the cart must have products before freezing and only five frozen sales can be held at once.

Checkout controls
- Customer tab: add, change, view, or remove the customer on the sale.
- Payment tab: select and apply a payment method.
- Sales Team tab: select employees/sales representatives and adjust commission amounts.
- More: reveals extra checkout actions.
- Layaways: starts layaway mode from the checkout. It is disabled or blocked if the sale already has payments, if the sale is in quote mode, if the cart contains a Gift Card, or if the sale is tax exempt.
- Quotes: starts quote mode from the checkout. It can be disabled if the user lacks quote access, if the sale already has payments, if the sale is already a layaway, or if this checkout was opened from an existing quote.
- Discount: opens Add Discount for sale-level percentage, fixed, or tax-exempt discount options.
- Coupon: opens Coupons.
- Add Files: attaches files to the invoice.
- Back arrow/back action: returns to the prior checkout step or back to the sale when allowed.
- Next: moves to the next checkout step.
- Confirm Payment: applies the selected payment amount.
- Complete: finalizes the invoice or quote when required information is present.

Payment method controls
- Cash: shows Charged Amount, Custom, and quick amount buttons 1, 5, 10, 20, 50, and 100.
- Credit Card: shows Charge Amount and terminal instructions: Terminal Ready, Tap / Insert / Swipe card, or Manual Entry. Manual Entry uses Card Number, Expiry, and Cvv.
- Check: shows Charge Amount and Check Information with Name, Check No, Personal Check, and Traveler's Check.
- Gift Card: shows Charge Amount, Gift Card Information, Card Balance, Search gift card here, and Expiry Date.

Appointment controls
- Appointments: opens the appointment calendar.
- Location and User filters: filter the calendar view.
- Print Appointments: prints the current appointment view.
- Create Appointment: opens Add / Edit Appointment.
- Previous month, current month, next month: calendar navigation.
- Today, MONTH, WEEK, DAY, LIST: scheduler view controls.
- Appointment type checkboxes: filter appointments by type.
- Add / Edit Appointment: includes Add Customer, Delete, Recurrence, Print, AppointmentTypes, Add New Appointment Type, Start Date, Start Time, End Date, End Time, All Day Event, Location, Assign to, Notes, and Ok.

Troubleshooting navigation questions
- Ask which module the customer is in: Sales, Checkout, Appointments, Layaways, Quotes, CRM, Reports, or Back Office.
- Ask what button or field they see on screen.
- If a button is missing or disabled, check permissions, current checkout mode, whether items are in the cart, whether payments already exist, and whether the user is at the correct [Location Name].
- If the screen does not match the steps, ask whether they are in Storefront or Back Office, then guide them to the correct module.
