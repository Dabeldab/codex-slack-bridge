Nova Wave Storefront: create a new appointment type and create an appointment

Use this article when a customer asks how to create a new appointment type, add an appointment category/service, choose an appointment color, or create an appointment in Nova Wave Storefront.

Important concept
An appointment type is the reusable label/category that appears in the Appointment Type dropdown. The actual appointment is created after the type is selected and the customer/date/time/location/assigned user are filled in.

Screen: Add / Edit Appointment modal
The main appointment modal is titled Add / Edit Appointment and has a calendar icon in the red header. The X in the top-right closes the modal.

Top action buttons on this modal:
- Plus icon / Add Customer: opens customer selection or customer creation before saving the appointment.
- Delete with trash icon: removes an existing appointment. It may be disabled/greyed out when creating a new appointment or when no appointment is selected.
- Recurrence with circular-arrow/clock icon: use this only when the appointment should repeat.
- Print with printer icon: prints appointment information.

Appointment Type section controls:
- Appointment Type label: the section where the reusable type is selected.
- Add New Appointment Type with plus icon: opens the Add / Edit Appointment Type modal.
- AppointmentTypes dropdown: click the dropdown field or caret to select an existing appointment type.
- Appointment type dropdown list: includes a search area/icon, a scroll bar when there are many types, appointment type rows, and a color dot beside each appointment type.

Date & Time section controls:
- Start Date field
- Start Time field
- End Date field
- End Time field
- All Day Event checkbox: check this only if the appointment lasts all day instead of using specific start/end times.

User & Location section controls:
- Location dropdown: select [Location Name].
- Assign to dropdown: select [Employee Name] or [User Name].
- Notes field: enter optional internal notes for the appointment.
- Ok button: saves the appointment.

How to create a new appointment type
1. Open the Add / Edit Appointment modal from the Storefront calendar or appointment screen.
2. In the Appointment Type section, click Add New Appointment Type.
3. The Add / Edit Appointment Type modal opens. It has a calendar icon in the red header and an X close button in the top-right.
4. In the Appointment Name field, enter [Appointment Type Name].
5. Optional: choose an Appointment Background Color. The color button shows a colored square and a small dropdown arrow. Clicking it opens the color picker.
6. In the color picker, choose a color from the color square, hue slider, opacity slider, HEX/R/G/B/A fields, or preset color squares. The color gives appointments visual distinction on the calendar.
7. Click Save in the Add / Edit Appointment Type modal.
8. Return to the Add / Edit Appointment modal.
9. Click the AppointmentTypes dropdown and select [Appointment Type Name]. If the list is long, use the search area/icon or scroll bar to find it. The type should appear with its selected color dot.

How to create/save the appointment after the type exists
1. In the Add / Edit Appointment modal, select [Appointment Type Name] from the AppointmentTypes dropdown.
2. If a customer is needed, click Add Customer and select or create [Customer Name].
3. Set Start Date.
4. Set Start Time.
5. Set End Date.
6. Set End Time.
7. If the appointment is all day, use the All Day Event checkbox instead of normal start/end times.
8. In Location, choose [Location Name].
9. In Assign to, choose [Employee Name] or [User Name].
10. Add optional notes in the Notes field.
11. Click Ok to save the appointment.

If the appointment type is missing after saving
- Reopen the AppointmentTypes dropdown and use the search area/icon.
- Scroll the dropdown list and look for [Appointment Type Name] and its color dot.
- Confirm Save was clicked in the Add / Edit Appointment Type modal.
- Refresh Storefront and reopen the Add / Edit Appointment modal.
- Confirm the user is in the correct [Location Name] and has permission to create or edit appointment types.
- If the type still does not appear, collect [Account Name], [Location Name], [User Name], the appointment type name, the color chosen, and the time the type was created, then escalate.

If the appointment does not save
- Confirm Appointment Type, Start Date, Start Time, End Date, End Time, Location, and Assign to are filled in.
- Confirm End Date/End Time is after Start Date/Start Time unless All Day Event is checked.
- Confirm required customer information is present if the workflow requires a customer.
- If Ok does nothing or the modal stays open, collect the browser/device, [Account Name], [Location Name], [User Name], fields entered, and any error message, then escalate.
