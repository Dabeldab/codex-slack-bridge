What is a Price List?	A Price List is an account-level pricing scheme used to control product prices by location and by pricing scenario.
What is the Default Price List?	The Default Price List is the baseline pricing list for the account. Every product is automatically in it, and every location is automatically assigned to it unless another Price List is applied.
What happens if I edit the Default Price List?	Editing the Default Price List changes the actual underlying product pricing data in the account repository.
Who can access Products -> Price Lists?	Owner, Partial Owner, and Product Manager can access Products -> Price Lists within regions they can access.
How do I create a new Price List?	Go to Back Office -> Products -> Price Lists and click Add New Price List. Enter Price List Name, optionally select locations, review the copied products and pricing data, then click SAVE.
Can I create a Price List first and assign it later?	Yes. You do not have to assign locations during creation. You can build the Price List first and assign it later.
Can I assign a Price List to more than one location?	Yes. Location assignment can be multiple. You can select one, many, or all locations.
Can one location have more than one Price List?	No. A location can have only one applied Price List at a time.
How do I assign a Price List to a store?	You can assign a Price List from the Price List create or edit screen by using Select Location, or from Back Office -> Locations -> Settings -> Edit -> Preferences -> Price List.
Where do I assign a Price List to a location?	Go to Back Office -> Locations -> Settings -> Edit -> Preferences -> Price List, or assign locations directly from the Price List create or edit screen.
How do I make specials in the store?	Use Products -> Price Lists to create alternate pricing and assign it where needed.
Can I run a promo in one store only?	Yes. Use Products -> Price Lists for a store-only promo. Assign the special Price List only to that location.
How do I create a store-only promo?	Go to Back Office -> Products -> Price Lists, click Add New Price List, enter the Price List Name, update the copied products with the special pricing, assign the Price List only to the target location with Select Location or from Locations -> Settings -> Edit -> Preferences -> Price List, then save.
How do I create holiday pricing?	Use Products -> Price Lists. Create a custom Price List, update the prices you want for the holiday period, then assign that Price List to the location when ready.
Can I use the Default Price List to update all product prices without making a custom Price List?	Yes. The Default Price List can be used as a direct bulk-pricing tool, but editing it changes the actual underlying product pricing data in the account repository.
What happens if I remove a custom Price List?	Removing a custom Price List permanently deletes it. It is not archived and cannot be restored.
Can I search inside a Price List by barcode or SKU?	Yes. In the Price List create or edit screen, the search field can search Barcode 1, Barcode 2, SKU, Product Name, Category Name, and Description.
