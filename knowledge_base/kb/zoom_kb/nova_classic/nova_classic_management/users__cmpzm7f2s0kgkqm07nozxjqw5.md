Management Screen > Users
Q: What is the Users section used for?

A: Use Management Screen > Users to add employees, edit employees, activate or deactivate users, assign regions, assign access levels, create custom roles, reset passwords, manage fingerprint options, and set salary or commission rules.

In Nova Classic, user, employee, and person in Nova usually refer to the same user record.

Q: How do I open Users settings?

A:

Go to the Management Screen.
Click Users.
Click Settings.
Choose Active Users, Inactive Users, or Users from all regions.
Click add a new user to create a user, or click Edit on an existing user.
Q: Who can access Users > Settings?

A: Owner, Partial Owner, and Regional Manager access levels can access Users > Settings when their permissions allow it.

If the customer cannot see Users > Settings:

Confirm they are signed in with the correct user.
Confirm that user has the needed access level.
If they use a custom role, confirm the custom role includes user settings access.
Q: How do I create a new user or employee?

A:

Go to Users > Settings.
Click add a new user.
Enter User Name. This is required.
Enter optional information such as Full Name, Password, Position, Email, Mobile #, Landline, Carrier, SSN / ID, and Badge Number.
Choose the user's Primary Region.
Select the user's Accessible Regions.
Review User Access Levels, Nova Roles, and Custom Roles.
Review User Salary if the business uses Nova for salary, hourly pay, or commission.
Click Save, Save and New, or Save and Clone.

Only User Name is required, but the user should have the correct region and access before they begin using Nova.

Q: What user name rules should I know?

A: When creating or editing a user:

Enter a User Name with at least 2 characters.
Do not reuse a user name that already exists, even if the existing user is inactive.
Remember that user names are not case sensitive.
User names can include spaces, numbers, and special characters.
Click Save when finished.
Q: Does a user need a password?

A: No. A password is optional, but privileged users should have strong passwords.

To set or change a password:

Go to Users > Settings.
Open the user.
Enter the password in Password.
Click Save.

If the user has an email on file, Nova can use it for forgot-password behavior and paycheck emailing when those workflows are used.

Q: How do I change an employee's password?

A:

Go to Users > Settings.
Click Edit on the employee.
Enter the new value in Password.
Click Save.

If the customer is trying to recover a password by email, first confirm that the employee record has an Email saved.

Q: How do I activate or deactivate a user?

A:

Go to Users > Settings.
Open the user.
Check Active User if the user should be active.
Uncheck Active User if the user should be inactive.
Click Save.

Nova normally deactivates users instead of deleting them. Inactive users can still be opened and edited. User ID 1 cannot be deactivated.

Q: Can I delete a user?

A: No. In this workflow, Nova deactivates users instead of deleting them.

To remove access:

Go to Users > Settings.
Open the user.
Uncheck Active User.
Click Save.
Q: Can I reactivate an inactive user?

Open the inactive user.
Check Active User.
Confirm regions and access are still correct.
Click Save.

Q: Why are breaks still included in pay after I checked the box to not include break time?

A: I know that can be confusing, especially after you already turned the setting on. In Nova, break times are only excluded from hourly pay for clock-ins made from the sales screen, and only for clock-ins made after the option has been enabled.

Use this checklist:

Confirm the option to not include break time in total pay is enabled.
Confirm the employee clocked in from the sales screen.
Confirm the clock-in happened after the option was turned on.
If the option was enabled on a different PC than the one where employees clock in, restart Nova on the clock-in PC.
After restarting Nova, have the employee clock out and clock back in from the sales screen.
Review the next payroll/user report after the new clock-in.

The setting does not automatically recalculate older clock-ins. It also will not affect the clock-in PC until that PC has picked up the changed setting, which is why restarting Nova and clocking out/back in may be needed.

Q: How do Nova Roles and Custom Roles work?

A: Nova Roles are preset groups of access. Custom Roles let the owner choose exact permissions from the Access Roles tree.

To use them:

Scroll to User Access Levels.
Use Nova Roles when a preset role matches the employee's job.

Enter a Role Name.
Check only the access boxes that role should include.
Click Save in the role editor.
Back on the user record, check the new custom role.

A: Nova validates the custom role before saving it.

Common messages:

You must name the role you are attempting to save means Role Name is blank.

Q: How do commission steps work if the From field is greyed out?

A: The From($) field can be calculated automatically from the prior step.

Use this setup:

Go to Users > Settings.
Open the user.
Go to User Salary.
Enable Comission Steps.
In Step 1, the From($) value starts at zero.
Enter the Step 1 To($) amount.
Nova uses the next amount as the following step's From($) value.
Enter each step's To($) and Comission(%).
Save the user.

To change where Step 2 starts, change where Step 1 ends.

Q: What is the difference between Retro and non-retro commission?

A: Retro controls whether the reached commission percentage applies to the whole qualifying amount or only the amount inside that step.

Where to find it:

Go to Users > Settings.
Open the employee.
Go to User Salary.
Enable Comission Steps.
Review From($), To($), Comission(%), and Retro.
Click Save after changes.

Simple explanation:

Without Retro, each step pays its own commission percentage for that step's range.
With Retro, once the employee reaches that step, the step percentage can apply back to the full qualifying sales amount.
Commission steps are calculated by total sales per day.
Save the user after changing commission rules.

Example:

Step 1 is From($) 0 to To($) 100 at 5%.
Step 2 is From($) 100 to To($) 200 at 10%.
If the employee sells 150 in a day without Retro, the first 100 can pay at 5% and only the next 50 can pay at 10%.
If Retro is checked for the 10% step, reaching that step can make the 10% rate apply back to the qualifying sales amount.

Common mistakes:

From($) may be greyed out because Nova calculates it from the previous step's To($) value.
To change where Step 2 starts, change where Step 1 ends.
Retro can change payroll totals significantly, so use a test example with the customer before changing live payroll settings.
The source screen spells the fields as Comission Steps and Comission(%).
Q: Is commission calculated before tax and after discount?

A: Training material indicates employee commission is based on sales totals after discount and before tax, not on wholesale cost.

Customer-safe explanation:

Discounts reduce the sale amount used for commission.
Tax is not treated as employee sales commission.
Wholesale cost is not used as the employee's sales commission base.
If a customer's payroll result looks wrong, compare the invoice subtotal, discount, tax, user assignment, and commission settings.

Route detailed payroll disputes to support after gathering the user, date range, invoice examples, and expected result.

Q: What happens when I manually add hours with Add a Day in User Reports?

A: When you use Add a Day in the user report, Nova adds the total number of hours worked for that day. It does not create clock-in and clock-out times.

Use it this way:

Go to the user report or salary report area.
Choose the employee and date range.
Click Add a Day.
Select the day.
Enter the total hours worked for that day.
Select the location.
Click Add.

After the day is added, the user can go back to that day and edit the clock-in/clock-out times to change the total hours for that specific day.

Break-time note:

Manually entered check-in/check-out records do not calculate breaks.
Any manually added clock-in and clock-out time will include the full time between those entries.
To avoid break time being included when manually adding clock times, enter exactly one clock-in and one clock-out that totals the employee's actual working hours for that day.

Example: if the employee was at the store from 9:00 AM to 5:00 PM but took a 30-minute unpaid break, manually enter a single time range that totals 7.5 working hours, such as 9:00 AM to 4:30 PM, instead of entering the full 9:00 AM to 5:00 PM range.

This is best when the store only needs the total paid hours for the day. If the customer needs an actual clock-in or clock-out record for audit/history, use the check-in/check-out entry option, but explain that manual break calculation does not apply there.

Q: What should employees do if the store is open past midnight?

A: If the business needs employee hours split correctly across days, the common workaround is to clock out before midnight and clock back in after midnight.

Example:

Clock out near the end of the day, such as 11:59 PM.
Clock back in after midnight, such as 12:01 AM.
Review the user's hours later in the salary or user report.

This keeps the hours easier to review by date.

Review access roles/custom permissions if the user can sign in but cannot open a screen.
If fingerprint login is required, review Force login with fingerprint only.

If the employee appears in one region but not another, the issue is usually region/location access rather than the employee record being deleted.

What does the Carrier field affect?

The Carrier field sits beside Mobile # in the Edit User window. It is used for SMS-style notification workflows where Nova needs to know the phone carrier. If a user is not receiving text alerts, check the mobile number, carrier, active status, and the alert settings tied to the location or user role.
