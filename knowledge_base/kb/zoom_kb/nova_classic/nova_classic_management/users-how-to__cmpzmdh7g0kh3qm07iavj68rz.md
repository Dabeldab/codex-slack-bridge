Customer-Facing Navigation

From the Management Screen, click Users.

The key customer-facing route for user setup is Users > Settings.

In Nova Classic, "user," "employee," and "person in Nova" usually refer to the same record.

Users > Settings

Use Users > Settings to add users, edit users, activate/deactivate users, assign regions, set roles/access, and configure salary.

Steps:

From the Management Screen, click Users.
Click Settings.
Choose Active Users, Inactive Users, or Users from all regions.
Click add a new user, or click Edit on an existing user.
Make changes.
Click Save, Save and New, or Save and Clone.

Add A New User

Steps:

Go to Users > Settings.
Click add a new user.
Enter User Name. This is required.
Enter Full Name, Password, Position, Email, phone numbers, and address fields as needed.
Choose Primary Region.
Select Accessible Regions.
Review User Access Levels, Nova Roles, and Custom Roles.
Review User Salary if the business uses Nova salary/payroll.
Click Save.

Important rules:

User Name must be at least 2 characters.
User names must be unique.
User names are checked without case sensitivity.
At least one region must be selected.
Password is optional.
User ID 1 cannot be deactivated.

Activate Or Deactivate A User

Steps:

Go to Users > Settings.
Open the user.
Check or uncheck Active User.
Click Save.

Notes:

Nova does not normally delete users from this workflow; it deactivates them.
Inactive users can still be opened and edited.
User ID 1 cannot be deactivated.
Change A Password

Steps:

Go to Users > Settings.
Open the user.
Enter the new Password.
Click Save.

Important:

If the user has an email on file, the forgot-password function can email the password.
If there is no email on the user record, forgot password and paycheck emailing will not work for that user.

Customer-facing guidance:

Start with the standard Nova role that best matches the employee's job.
Use custom roles only when the user needs one specific permission or a special combination.
Avoid giving owner-level roles unless the employee truly needs sensitive access.
Custom Roles / Access Levels

Use custom roles when standard Nova roles are too broad.

Steps:

Open Users > Settings.
Open the user.
Go to Custom Roles or open the access-role editor.
Choose an existing custom role, or choose Create a New Role.
Enter New Role Name.
Select the permissions needed.
Click Save.

Common Customer Questions
Can I reuse a username from an inactive user?

No. User names must remain unique, even when the old user is inactive.

Does a user need a password?

No. A password is optional, but privileged users should use strong passwords.

What is the difference between the user's title and access level?

The title/position under the name is informational. The real access comes from roles, custom roles, and access levels.

How do I reset a fingerprint?
Go to Users > Settings.
Open the user.
Click Reset fingerprint.
Save the user.
Have the user enroll/sign in again as needed.
