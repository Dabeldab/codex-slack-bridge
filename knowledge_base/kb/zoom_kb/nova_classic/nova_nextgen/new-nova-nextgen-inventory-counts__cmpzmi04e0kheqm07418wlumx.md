Q: How do I open Inventory Counts?

A:

Log in to New Nova.
Select a Region.
Click the blue menu button in the top-right.
Click Inventory Counts.

Open Inventory Counts from the clicked blue menu. If the customer is on a 404 page, return to the main tenant URL and click the menu item again.

Q: What is displayed on the Inventory Daily Counts screen?

A: The Inventory Counts list shows submitted inventory counts and their review status.

Visible controls and columns include:

Inventory Daily Counts
Page-action dropdown with Add Count
Add a Filter
Count #
Location
Submitted By
Notes
Last Modified By
Status
Action

Statuses can include Error in count when the count has mismatches or needs review.

Q: How do I create a new inventory count?

A:

Open Inventory Counts.
Click the page-action dropdown in the upper-right of the Inventory Counts header.
Click Add Count.
Select Location.
Use Print if a paper count sheet is needed before entering counts.
Enter Comments if needed.
Choose Count By:
Product
Categories
Families
Enter counts in the table.
Click Save.

The New Inventory Count screen can show Location, Print, Comments, Count By, Product, Categories, Families, Image, Product, Category, Last Count, Expected Count, Save, and Back.

Q: What should I check before saving an inventory count?

A: Review the count table before saving so the count does not create bad inventory adjustments.

Confirm the correct Location is selected.
Confirm the correct Count By mode is selected.
Compare Last Count and Expected Count.
Enter the counted quantity in the count field.
Add Comments explaining unusual differences.
Save only after the location, count mode, and quantities are correct.

Common mistake: selecting the wrong location, especially when the user has access to multiple regions or locations.

Q: What does Reviewed? do on an inventory count?

A: Reviewed? marks the count as reviewed after a manager checks it.

Open the inventory count.
Compare Expected and Count.
Use Fix only when the count should be applied.
Add comments if needed.
Turn on Reviewed?.
Save.

Do not mark a count reviewed until the count has been checked.

Q: Why does an inventory count show Error in count?

A: Error in count usually means the count has mismatches or incomplete count data.

Open the count.
Compare Expected against Count.
Look for blank counts or incorrect quantities.
Use Fix for verified product differences.
Use Remove Count only for a count line that should not be part of the count.
Save and mark reviewed when finished.
