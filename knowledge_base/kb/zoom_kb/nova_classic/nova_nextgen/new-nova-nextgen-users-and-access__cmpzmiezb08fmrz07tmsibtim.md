Q: Why can't a user sign in to New Nova?

A: Check both the web login and the employee setup.

Confirm the company web address is correct.
Confirm the employee is using the correct username and password.
If Your Session Has Expired appears, treat it as the login screen and log in again.
In New Nova, open Users from the blue menu.
Open the employee.
Confirm the user is active.
Check User Info for name, email, phone, carrier, and notes.
Check System Access for New Nova/POS management access and the screens the user needs.
Save changes.
Have the user log out and log back in.

If the Region dropdown is blank on the web version, click the blue menu and select a screen first. This can load the region context.

Q: What does "User does not have POS Management access" mean?

A: It means the employee can exist in Nova but does not have the access needed for the management area or selected New Nova screen.

A manager should open Users.
Open the employee record.
Go to System Access.
Enable the correct management/New Nova access and screen permissions.
Save.
Have the employee sign out and back in.

Do not solve this by sharing another user's login. Fix the user's own access.

Q: Why can a user see a screen but not edit it?

A: View access and edit access can be different.

Open Users.
Open the employee.
Review System Access.
Confirm the user has the specific permission for the action, not just the screen.
For invoices, check permissions such as invoice access, refund access, commission edit access, and reviewed/edit controls.
For products/inventory, check product settings, inventory update, transfer, purchase order, change log, and loss/report permissions.
Save and have the user log in again.

If the user can open the screen but a button is disabled or missing, permissions are a likely cause.

Q: Why does a user not show in the sign-in list or cannot change locations?

A: Check active status, region/location access, and system access.

Open Users from the blue menu.
Search for the employee.
Confirm the employee is active.
Open the employee.
Check System Access.
Confirm the employee is assigned to the correct region/location or has all-region access if needed.
Save.
Have the employee log out and back in.

If the user is locked to one location in Classic/location settings, they may not be able to switch locations until that setup is changed.

Q: What fields are on the New Nova User form?

A: The New Nova user form includes:

User Info.
System Access.
Select Image.
First Name.
Last Name.
Gender with Male and Female.
Email.
Social Security.
Date of Birth.
Phone Number.
Carrier.
Can't find your carrier?
Address.
Add File.
Notes.
Back to Listing.

Use System Access when the question is about what the user can open or edit. Use User Info when the question is about employee details.

Q: Why is the carrier field important on a user?

A: The Carrier field supports phone/SMS-style notification workflows. If alerts or text-style messages are not working for a user, check:

Phone Number.
Carrier.
Active user status.
Notification/alert settings.
Whether the business should use app/email alerts instead of carrier-routed SMS.
