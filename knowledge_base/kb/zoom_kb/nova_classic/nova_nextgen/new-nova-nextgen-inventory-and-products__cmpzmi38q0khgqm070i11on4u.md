Q: How do I open Inventory in New Nova?

A:

Log in to New Nova.
Select a Region.
Click the blue menu button in the top-right.
Click Inventory.

If the browser is already showing a direct URL error or a blank screen, go back to the main tenant URL first, then use the blue menu. Inventory should be opened by clicking Inventory, not by pasting /products/listing.

Q: Are Product Settings and Inventory Management separate in New Nova?

A: No. In New Nova / NextGen, product setup and inventory control are combined into the same Inventory screen.

If the customer says Product Settings, Products > Settings, Inventory Management, or Inventory > Management, route them to Inventory in New Nova. It does not matter which older Classic-style wording they use; both product settings tasks and inventory management tasks are handled from the combined Inventory menu.

Use Inventory for:

Finding products.
Editing a product.
Adding a product.
Product import/export.
Product price review and direct price edits.
Quantity lookup.
Quantity updates.
Report loss.
Removing or adding products to a location.
Printing selected product labels.

Q: How do I add a product?

A:

Q: How do I open an existing product from Inventory?

A: In New Nova, use the combined Inventory screen.

Open Inventory.
Select the correct Location if the question is location-specific.
Use the search box or Add a Filter to find the product.
Click the product Name to open the product, or open the row Action menu and click Edit.
Use the left-side tabs:
Product Details for name, description, category, vendor, commission, image, and variants.
Pricing for cost, minimum, suggested price, negotiable settings, and price-list pricing.

If the customer only needs to change the visible price and a specific Location is selected, they can click the blue price from the Inventory list instead of opening the full product.

Q: What do Save, Save and Create New, and Save and Clone do on a product?

A: These buttons decide what happens after saving the product.

Save saves the product and returns to the normal flow.
Save and Create New saves the product and opens another blank new product form.
Save and Clone saves the product and starts another product using the same or similar details.

Use Save and Clone only when the next product should share most of the same setup.

Q: How do I edit a product price directly from the Inventory list?

A: Select a location first, then click the blue price in the Inventory list.

Open Inventory.
Select the correct Location. Do not use All Locations for this direct price edit.
Use Add a Filter or the search field to find the product.
Find the Price or Price (Default Price List) column.
Click the blue price amount. If the product shows Between: two blue amounts, click the amount that needs to be changed.
Edit the price in the price edit prompt or inline editor.
Save or confirm the update.
Recheck the product row to confirm the price changed.

The customer does not have to open the product with Action > Edit for this quick price change. Use Action > Edit only when they also need to change product details, identifiers, pricing settings, inventory tracking, variants, category, vendor, or other product setup fields.

Q: How do I bulk update inventory quantity?

A: This is one of the main New Nova differences from Classic. Use it carefully because it applies to multiple selected products.

Open Inventory.
Select a specific location. Do not use All Locations for quantity bulk updates.
Filter the list if needed.
Select the products.
Open the batch action menu.
Choose Update Quantities.
In Update Inventory Quantity, choose:
Set to
Add
Deduct
Enter the quantity.
Read the warning text.
Click Update.
Confirm Apply Update.

The modal explains what will happen:

Set to sets the available quantity to the entered number for all selected products.
Add adds the entered number to all selected products.
Deduct deducts the entered number from all selected products.

Common mistakes:

Set to is not the same as Add.
If the user selects too many products, every selected product changes.
If the user is filtered to the wrong location, the wrong location inventory changes.
Q: What bulk actions are available from the Inventory list?

A: Inventory list bulk actions are available after selecting products in Inventory. The available actions depend on the selected location and the user's access.

Update Quantities
Assign Category
Add to this location
Remove from this location
Print Labels

Important access and location rules:

Update Quantities needs a specific location selected. Do not use All Locations.
Add to this location and Remove from this location need inventory access.
Remove from this location is disabled when All Locations is selected.
Print Labels needs label/price-tag access and a specific location.
Print Labels should be used with selected rows, not a broad "select all results" state.

Use this general workflow for any Inventory bulk action:

Open Inventory.
Select the correct Region and a specific Location when the action changes location inventory.
Filter the product list.
Select only the products that should change.
Choose the batch command.
Review the confirmation modal.
Apply the update.

Do not use bulk actions until the visible product list and selection are correct.

Q: How do I remove multiple products from a location?

A: Use Remove from this location from the Inventory batch action menu.

Open Inventory.
Select the correct Region.
Select the exact Location. Do not use All Locations.
Use Add a Filter if needed to narrow the list.
Select the products that should be removed from that location.
Open the batch action menu.
Click Remove from this location.
Read the confirmation. New Nova can show Removing product(s) from location: and warn that a product may be deleted permanently if it is not active in any other location.
Confirm only if those products should no longer be active at that location.
Recheck the product list after the update.

Common mistakes:

Removing from the wrong location because the location selector was not checked first.
Selecting more products than intended after using a broad filter.
Removing a product that only exists in one location, which can delete it permanently.
Q: How do I add multiple products to a location?

A: Use Add to this location from the Inventory batch action menu.

Open Inventory.
Select the correct Region and Location.
Filter the product list to the products that should be added to the location.
Select the products.
Open the batch action menu.
Click Add to this location.
Read the confirmation. New Nova can show Adding product(s) to location: and ask the user to confirm.
Confirm the update.
After the products are added, update their quantities if needed.

New Nova adds the selected products to the location at quantity 0. If the store has stock on hand, use Update Quantities after adding them.

Q: How do I bulk update product details such as barcodes or SKU?

A: Use the product details batch modal only after selecting the correct products.

Open Inventory from the blue menu.
Select a location.
Filter the product list.
Select the products that should receive the same detail update.
Open the batch action for product details.
In Update Product Details, enter only the shared values that should change.
Review fields such as Barcode1, Barcode2, and SKU.
Click Update.
Confirm Apply Batch.

Use this only when the selected products should share the entered value or when updating variant identifiers from a shared base value. For variants, New Nova can append a counter or suffix to additional selected variants for Barcode1 and Barcode2. SKU is treated as a shared value, so do not use the batch modal if each selected item needs a different SKU.

Do not use this if every product needs a completely different barcode or SKU. For unique values, use the product form, the variant matrix, or product import.

Q: How do I generate multiple barcodes for product variants?

A: Use the variant/product creation matrix when a product comes in options such as size, color, style, or scent.

Open Inventory.
Add a new product, click the product Name, or use Action > Edit on an existing product.
Open Product Details.
Turn Does this product come in different variants (example: color, size)? to YES.
Add an option such as Size, Color, or Style.
Enter the option Values. Values can be typed into the value box and separated by commas.
To use a custom option, open the option dropdown, click Custom, and enter the custom variable name, such as Scent, Finish, Length, or Package.
Add the custom option values.
Click Generate Variants.
Review the generated variant rows.
Open Inventory.
Use the variant identifier fields such as Barcode1, Barcode2, and SKU.
Use the bulk barcode option if the variants should be generated from one barcode base.
Review the generated barcode suffixes or generated barcode values before saving.
Click Save.
Print labels only after confirming the generated barcodes are correct.

New Nova generates one variant per value for a single option. When multiple option groups are used, New Nova generates combinations. Example: 3 sizes and 2 colors creates 6 variants.

Q: How do I bulk generate barcodes for all variants of one product?

A: Generate the variants first, then use the variant identifier tools.

Open Inventory.
Click the product Name or use Action > Edit.
Open Product Details.
Confirm Does this product come in different variants (example: color, size)? is set to YES.
Confirm the options and Values are correct.
Click Generate Variants if the variant rows have not been created yet.
Open Inventory for the product.
Find the Identifiers area for the variant rows.
Select the variants that should receive generated barcodes.
Use the available bulk identifier/barcode action.
Enter the barcode base or starting barcode value.
Review the generated Barcode1 and Barcode2 values for each variant.
Do not use a shared SKU value if each variant needs its own SKU.
Click Update or confirm the batch update.
Click Save on the product.
Print labels only after confirming the variant barcodes are correct.

Use bulk barcode generation only when the variants should receive related generated barcode values. If the vendor already assigned unique barcodes to each size/color, enter those exact barcodes manually or import them from a product file.

Q: How do I use the product creation matrix in Add Product or Edit Product?

A: The customer-facing name may be "product creation matrix," but the New Nova form shows it as variant setup.

Open Inventory.
Click Add Product, click the product Name, or use Action > Edit.
Open Product Details.
Complete the normal product fields first, such as Product Name, Description, Category, Preferred Vendor, Sales Screen Position, Select Image, and Commission.
Turn Does this product come in different variants (example: color, size)? to YES.
Add Option 1.
Choose an existing option such as Size, Color, or Style, or choose Custom.
If using Custom, enter the custom variable name the business wants employees to recognize.
Add the Values for that option. Type values into the value box, separated by commas when adding multiple values.
Add Option 2 if the product also varies by another variable, such as color and size.
Click Generate Variants. This step is required before the variant rows are created.
Review the generated variant rows. One option creates one row per value. Two options create combinations.
Open Pricing.
Review or bulk update the variant cost, minimum, suggested price, negotiable setting, sales-above setting, sales-below setting, and tax-included setting.
Open Inventory.
Review Inventory Policy, Do not Track, Track Inventory, Identifiers, and Quantities.
Update quantities for the generated variants if needed.
Click Save.

Use the matrix when the item is one product with multiple sellable versions. Do not create separate unrelated products in the matrix just because they share a category.

Q: What do the product matrix options mean?

A: Product matrix options define the sellable versions of one product.

Does this product come in different variants (example: color, size)? turns the product matrix on or off.
Option 1, Option 2, and additional options are the variable names, such as size, color, style, scent, or package.
Existing Options are built-in option names such as Color and Style.
Custom lets the business create its own option name when size, color, or style does not fit.
Values are the choices for that option, such as small, medium, large, blue, green, red, 30 ml, or 60 ml.
Remove Option removes an option group from the matrix.
Generate Variants creates the actual variant rows from the selected options and values.

Example: if Option 1 is Size with values small, medium, large and Option 2 is Color with values blue, green, red, New Nova creates combinations for each size/color pair after Generate Variants is clicked.

Common mistakes:

Turning the variant toggle to YES but not clicking Generate Variants.
Adding values but not saving the product.
Using Custom but leaving the custom option name blank.
Creating variants for unrelated products instead of only versions of the same product.
Forgetting to review Pricing and Inventory after generating variants.

Q: What is different about Products and Inventory in New Nova compared with Nova Classic?

A: In Nova Classic, Products > Settings and Inventory > Management are separate management areas. In New Nova / NextGen, they are combined under Inventory.

Use New Nova Inventory for:

Product setup.
Product editing.
Variant/product matrix setup.
Product import/export.
Direct price edits from the product list.
Quantity lookup and inventory control.
Product loss reporting.
Bulk add/remove/location/category/quantity/label actions.

Use Nova Classic Products > Settings when the customer is in the six-tile Classic Management Screen and needs Classic product fields such as product default price, fixed/non-fixed price, size, color, barcode, SKU, tax, category, button color, or active status.

Use Nova Classic Inventory > Management when the customer is in Classic and needs Classic inventory workflows such as update inventory, view by item, daily counts, testers/losses, transfers, or purchase orders.

Important difference: New Nova has the product creation matrix for variants inside the product form. Classic product answers should not send the customer to the New Nova matrix unless they are actually using New Nova.

Q: How do I bulk edit cost, minimum, suggested price, markup, and pricing settings inside a product?

A: Use Update Pricing from the product pricing table batch action. Customers may call this "markup," but the New Nova label is usually Suggested or Suggested Price.

Open Inventory.
Open the product with Edit.
Open Pricing.
Select the price rows or variant price rows that should change.
Open the pricing batch action.
Click Update Pricing.
In the modal, use Check the fields you want to update in bulk.
Check only the fields that should change.
Enter Cost if the product cost should change.
Enter Minimum and Suggested values if the selling range should change.
Use Negotiable when the item should allow a price range.
Use Allow sales above price when employees may sell above the suggested price.
Use Allow sales below minimum price when employees may sell below the minimum price.
Use Tax included when the displayed price already includes tax.
Click Update.
Confirm the batch update.

Only checked fields update. If Cost is filled in but its checkbox is not selected, the cost should not be changed by the bulk update.

Q: What is the difference between Inventory bulk pricing, product pricing bulk update, and price-list bulk update?

A: These three workflows look similar but affect different scopes.

Inventory list bulk actions start from Inventory after selecting product rows. Use these for selected products at the list level.
Product pricing bulk update starts inside one product on Pricing. Use this for selected price rows, selected price lists, or selected variants inside that product.
Price-list bulk update starts inside Price Lists. Use this when many products inside the same price list need the same percentage, dollar, or setting change.

Before applying any pricing bulk action, confirm the selected rows, selected location or price list, and whether the change is a fixed value, percentage, or setting-only update.

Q: How do I set many product quantities to zero after a physical count?

A: Use Inventory bulk quantity update carefully.

Open Inventory from the blue menu.
Select the correct Location.
Use search or Add a Filter to narrow the list.
Select only the products that should be changed.
Open the Batch update for X product(s) menu.

Use the option that sets the selected products to an exact value.

Review the selected product count before applying.
Apply only when the selected list is correct.

Important: Set to 0 is different from deducting 0. Make sure the user is using the set-to/exact quantity behavior, not an add/deduct behavior.
