Q: Where is Import/Export for products in New Nova?

A: Import/Export is part of the Inventory screen.

Log in to New Nova.
Select the correct Region.
Click the blue menu button.
Click Inventory.
Open the Inventory page action dropdown.
Click Import/Export.

The Import/Export modal includes Import new products and Export products from Nova.

Q: How do I export products from New Nova?

A:

Open Inventory.
Open Import/Export.
Choose Export products from Nova.
Choose the export scope:
All items in the company when the customer needs the full product list.
Only items from current location when the customer needs just the selected location.
Select With Quantities if the export should include quantities.
Click Export File.
Open the downloaded file from the browser downloads.

If the export is too large or looks wrong, confirm the selected region/location, whether All items in the company was chosen, and whether the customer meant an inventory report instead of a product export.

Q: How do I import new products in New Nova?

A:

Open Inventory.
Open Import/Export.
Choose Import new products.
Click Download the import file template.
Fill out the template carefully.
Return to Import new products.
Use Browse or the upload control to select the completed file.
Click Import File.
Review any validation messages before continuing.

If the import shows errors, fix the spreadsheet and import again. Do not keep importing the same file without correcting the rows listed in the error message.

Q: What messages can appear during product import?

A: Source templates show both success and error states.

Possible messages include:

Errors were found.
Successfully imported.
OK.

Customer-facing troubleshooting:

If errors appear, read the error list before closing the modal.
Fix missing required product fields, invalid numbers, duplicate barcodes, category/vendor mismatches, or badly formatted rows.
Save the spreadsheet.
Upload the corrected file again.
Confirm the products from Inventory after import.
Q: Should I use Import/Export or Inventory Report?

A: Use them for different jobs.

Use Import/Export to move product setup data in or out of Nova.
Use Inventory Report to review inventory quantities, cost/value, sold/on-hand data, and report totals.
Use Print Labels when the customer needs labels rather than spreadsheet data.

If a customer asks for "all products with quantities," Export products with With Quantities may help. If they ask for inventory value or sold/on-hand reporting, use Inventory Report.
