Q: Where is the Inventory Report in New Nova?

A: Open it from New Nova, not from Nova Classic.

Log in to New Nova.
If the Region dropdown is blank on the web version, click the blue menu button and choose Inventory first so the app loads the region context.
Select the correct Region.
Open Inventory from the blue menu.
Use the Inventory page action/report option for Inventory Report when available.
Use Export To Excel if the customer needs the report as a spreadsheet.

Do not tell the customer to paste the report route directly into the browser. Direct route refreshes can show a server 404. Open the screen through the blue menu.

Q: What is displayed on the Inventory Report?

A: The source template for the New Nova Inventory Report shows report filters, totals, and item columns used for sold/on-hand inventory review.

The report can include:

Date Range.
Location or location-scope filters.
Cost and sale-type filters.
Total Items Sold.
Total Net Revenue Forecast.
Inventory Sold vs On Hand.
Product and variant fields such as Variant 1 and Variant 2.
Quantity Sold.
Quantity On Hand.
COGS.
Net.
Tax.
Gross.
Export To Excel.

Use this report when a customer asks for current inventory, inventory value, inventory sold versus on hand, cost/value review, or a spreadsheet export.

Q: How do I export an inventory report to Excel?

A:

Log in to New Nova.
Select the correct Region.
Open Inventory from the blue menu.
Open Inventory Report from the Inventory report/page action.
Set the date range and location/scope the customer needs.
Review the report before exporting.
Click Export To Excel.
Open the downloaded file from the browser download area.

If the export does not appear, check browser download blocking, pop-up blocking, session expiration, and whether the report was opened from the clicked New Nova shell rather than a direct URL.

Q: How do I see current inventory on hand or inventory value?

A: Use the New Nova Inventory screen for quick on-hand quantities and the Inventory Report for report/export review.

Open Inventory from the blue menu.
Select the correct Location.
Use Simple view for quick product, price, and quantity review.
Use Detailed view when the customer needs more product fields.
Open Inventory Report when the customer needs inventory value, cost, sold/on-hand comparison, or Excel export.
Review Quantity On Hand, COGS, Net, Tax, and Gross when those fields are included.

If totals look wrong, check the selected region/location, product cost, product active/tracked status, recent transfers, purchase order receiving, loss reports, and inventory counts.

Q: Why is my inventory report blank, different, or not loading?

A: Check the screen context first.

Open New Nova from the tenant root or from Nova Classic.
If the web page shows a blank Region dropdown, click the blue menu and choose Inventory to load the region context.
Select the correct Region and Location.
Open Inventory Report from inside New Nova.
Do not refresh or paste the direct report URL.
Widen the date range if the report is based on sold inventory.
Check whether the products are active and assigned to that location.
Check browser pop-up/download blockers if only the export is failing.
If Your Session Has Expired appears, log in again and reopen the report from the blue menu.

If the report is different from Classic, explain that New Nova has the current inventory report/export workflow and the layout can differ from older Classic screens.

Q: Can I see an out-of-stock or low-stock list?

A: Use Inventory filters or an Inventory Report export.

Open Inventory.
Select the Location.
Use Add a Filter.
Filter by quantity-related fields, such as current quantity or minimum quantity, when those filters are available.
Use the report/export workflow if the customer needs to sort or review the list in Excel.

If the customer expected an alert instead of a report, check the alert/notification setup separately. The report shows data; alerts depend on notification settings and permissions.
