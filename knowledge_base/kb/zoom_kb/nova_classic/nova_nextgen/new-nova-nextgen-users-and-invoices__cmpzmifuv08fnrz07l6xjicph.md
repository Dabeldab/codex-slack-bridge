Q: How do I open Users?

A:

Log in to New Nova.
Select a Region.
Click the blue menu button in the top-right.
Click Users.

Open Users from the clicked blue menu. Do not paste internal user routes into the browser.

Q: How do I add a user in New Nova?

A:

Open Users.
Click the page-action dropdown in the upper-right of the Users header.
Click Add New User.
Fill in User Info.
Add a photo with Select Image if needed.
Enter First Name and Last Name.
Choose Gender if needed.
Enter contact details such as Email, Phone Number, and Carrier.
Use Can't find your carrier? if the carrier is missing.
Enter Address and Notes if needed.
Use Add File for user documents if the business tracks files.
Review System Access.
Save.

The user model can show New, Back to Listing, User Info, System Access, Select Image, First Name, Last Name, Gender, Male, Female, Email, Social Security, Date of Birth, Phone Number, Carrier, Can't find your carrier?, Address, Add File, and Notes.

User info fields can include address/contact style fields such as street 1, street 2, city, state, country, zip, notes, gender, and phone carrier. The screen can also show Can't find your carrier? near phone carrier selection.

Q: How do I edit a user?

A:

Open Users.
Find the user row.
Open Action.
Edit the user.
Review User Info and System Access.
Save.

If a user cannot access a New Nova screen, check System Access and the user's NextGen access setting.

Q: What should I check when a user cannot see a New Nova menu item?

A: Check the user, region, and access settings before assuming the screen is missing.

Confirm the employee is logged in as the correct user.
Confirm a Region is selected in the top-right.
Click the blue menu button.
If the menu item is missing, open Users with a manager account.
Open the employee.
Review System Access.
Save access changes if the business wants that employee to use the screen.
Have the employee log out and back in.

Common mistake: the user is on the correct tenant but has not selected a region, so the menu does not show the expected working context.

For deeper access troubleshooting, use users_access.md.

Q: Where are invoices in New Nova?

A: Invoices can be opened from Dashboard tables, customer dashboards, or invoice links. The route exists in the New Nova UI bundle, but it may not appear as a top-level blue-menu item for every user.

Use these entry points:

Open Dashboard and use the Invoices table.
Open Customers, open a customer dashboard, and review customer invoices.
Open an invoice link from another screen when available.

Do not send customers to a pasted invoice route unless the app has already opened that invoice link. If a direct invoice link shows 404, return to the main tenant URL and open the invoice through Dashboard or Customers.

For deeper invoice print, refund, duplicate, notes, and permission workflows, use invoices.md.

Q: How do I find the layaway code on an invoice?

A: Open the invoice view screen and look in the invoice summary.

Open the invoice from Dashboard, a customer dashboard, or another invoice link.
Confirm the invoice number at invoice #.
Look for Layaway code: in the summary.
Give the customer the code exactly as displayed.

If Layaway code: is not shown, the invoice may not be a layaway or the selected invoice may not be the correct one.

Q: How do I add or review invoice notes?

A:

Open the invoice.
Go to Notes.
Enter notes in Comments.
Use the field placeholder invoice comments here... as the note area.
Save if editing is allowed.
Q: Why can a user see a screen but not edit it?

A: New Nova checks user access before allowing edits.

Confirm the user is logged in as the correct employee.
Confirm the selected region and location.
Open Users.
Review the user's System Access.
Update access only if the business wants that employee to perform the action.

Examples:

Product editing needs product settings access.
Inventory quantity changes need inventory access.
Transfer send/receive needs transfer access.
Purchase orders need purchase order access.
Labels need product label/price tag access.
