Q: How do I open the Dashboard?

A:

Log in to New Nova.
Select a Region.
Click the blue menu button in the top-right.
Click Dashboard.
Q: What is displayed on the Dashboard?

A: The Dashboard gives a high-level view of sales, invoices, employees at work, and payment activity.

The live Dashboard showed:

Location selector.
Date range selector.
Sales total type selector such as gross, net, or tax when available.
Revenue.
Cost of Goods Sold.
Invoices.
Estimated Profit.
Top Sales by Users.
Sales by Locations.
Sales by Products.
Payment Methods.
Who is at Work?

Dashboard tables may show:

Invoices: Invoice#, Offline#, Location, Time and Date, Total.
Layaways: Invoice#, Code, Location, Time and Date, Total.
Sales by Locations: Name, SubTotal, Tax, Total.
Sales by Products: Name, Description, Qty, Avg. sale price, Total(Net).
Sales by Users: Name, Spare, Net Sales.
Who is at Work: Name, Status, Last Update, Total time in, Total time out, Duration.
Q: Why does the Dashboard say Please select All Regions or All Locations?

A: Some Dashboard totals need a broad enough location selection.

Open Dashboard.
Review the Location selector.
Select All Regions or All Locations if the dashboard asks for it.
Recheck the Dashboard cards.

If only one location is selected, some dashboard calculations may not display.

Q: Why does Dashboard data look empty?

A: Empty Dashboard tables can be normal when the selected date range, region, or location has no matching activity.

Confirm the selected Region.
Confirm the Location selector.
Confirm the date range.
Check whether the store has invoices, payments, or clocked-in users for that period.
If the screen shows a login/session message, log back in and retry.
Q: Can I open invoice details from the Dashboard?

A: Yes. The Dashboard invoice table can list invoice rows.

Open Dashboard.
Use the date and location filters.
Find the invoice in the Invoices table.
Open the invoice row if an action or link is available.
Review the invoice view screen.

Use the Invoices table for quick lookup. Use the invoice detail screen when the customer needs products, payments, notes, customer, coupons, refunds, or reviewed status.

Q: How do I find a layaway code from the Dashboard?

A: Use the Dashboard layaway table when it is visible.

Open Dashboard from the blue menu.
Select the correct Region, Location, and date range.
Look for the layaway table.
Find the row by Invoice#, Location, Time and Date, or Total.
Read the layaway Code column.
Open the invoice if more detail is needed.

If the layaway table is empty, change the date range or open the customer dashboard and review the customer's layaways.
