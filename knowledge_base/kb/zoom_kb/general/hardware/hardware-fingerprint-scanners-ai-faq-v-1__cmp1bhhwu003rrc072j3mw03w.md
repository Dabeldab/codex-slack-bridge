Hardware — Fingerprint Scanners — FAQ
Q: My fingerprint scanner isn't working. What do I do?

A: Reconnect the scanner to the USB port, restart the workstation, then open Nova and test the scanner again. Many scanner issues clear after a reconnect and reboot. If the scanner is still not detected, call Nova support.

Q: How do I install a fingerprint scanner for Nova?

A: Connect the fingerprint scanner to the PC by USB, install any required driver if Windows doesn't recognize it automatically, restart the workstation, and test the scanner in Nova. For a UareU 450 / U.are.U scanner, use the Nova-provided driver setup package: https://drive.google.com/file/d/1AhAGjgnAy9Fm3iwKvPFiee2w_-EFqPmM/view?usp=drive_link. If Windows never detects the scanner or Nova cannot use it after a restart, call Nova support.

Q: My fingerprint reader isn't detected at all. What now?

A: Try a different USB port and a different USB cable if possible. Restart the workstation. If Windows still doesn't see the device, the driver may need to be installed manually — check the manufacturer's site for your scanner model. If detection still fails after that, call Nova support.

Q: I have an unknown fingerprint scanner. Which driver should I use?

A: First confirm the scanner's brand and model from the label, box, receipt, or Windows device listing. Then confirm the scanner is compatible with Windows. If it is Windows-compatible, download the driver from the scanner manufacturer's official website for that exact model. Do not install drivers from random third-party driver sites. If you cannot confirm the model, Windows compatibility, or the correct manufacturer driver, call Nova support.

Q: Why won't my employees' fingerprints scan?

A: First, restart the workstation and reconnect the scanner — this clears most issues. Test the scanner again in Nova after the restart. If specific employees still can't scan but others can, the fingerprint enrollment for those employees may need to be redone in Nova. If no fingerprints scan after a reconnect and reboot, call Nova support.

Q: My fingerprint scanner needs a driver — where do I get it?

A: Driver downloads must match your specific fingerprint scanner model. For a UareU 450 / U.are.U scanner, use the Nova-provided driver setup package: https://drive.google.com/file/d/1AhAGjgnAy9Fm3iwKvPFiee2w_-EFqPmM/view?usp=drive_link. For any unknown or different model, confirm it is compatible with Windows first, then use the manufacturer's official driver or call Nova support so an agent can verify the model and walk through the install.
