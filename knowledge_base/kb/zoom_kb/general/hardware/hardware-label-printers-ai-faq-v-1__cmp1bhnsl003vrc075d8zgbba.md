Hardware - Label Printers - FAQ
Q: How do I set up a Dymo label printer for product labels?

A: Connect the Dymo label printer to the Windows computer by USB and turn it on. Install the supported Dymo LabelWriter software, load the correct label size, then open Windows Settings > Bluetooth & devices > Printers & scanners and confirm Windows shows the printer online. Set the needed Windows/default device and label size, run a Windows test print, then in Nova Wave go to Back Office > Products > Labels & Price Tags, select the products/items, and click Print Labels.

Q: Which Dymo label printers are supported?

A: The documented compatible models are Dymo 450 and Dymo 450 Turbo. If the customer has a different Dymo model, ask for the exact model and route to Nova support before promising compatibility.

Q: Can a Dymo 430 label printer print customer receipts?

A: A Dymo 430 is a label printer, so treat it as a label-printing device, not the normal customer receipt-printer path. For customer receipts, use a supported thermal receipt printer such as Star Micronics TSP100 series or Epson TM-T20/TM-T88IV.

Q: My Dymo printer is in the printer list. Can I use it as the receipt printer?

A: No, not for the normal receipt-printer workflow. Dymo printers are for product labels. Nova Wave receipt printing uses the receipt printer installed in Windows as the Windows default printer/default device. Use a proper receipt printer for customer receipts and the Dymo workflow for labels.

Q: My label printer is not printing labels. What should I check?

A: Check power, USB cable, and label roll orientation. Confirm Windows shows the label printer online in Printers & scanners. Remove duplicate queues if needed, clear the Windows print queue, and run a Windows test print. Then return to Back Office > Products > Labels & Price Tags and try Print Labels again. If Windows cannot print to the device, call Nova support.

Q: Where do I print product labels in Nova Wave?

A: Go to Back Office > Products > Labels & Price Tags, select the products/items you want labels for, then click Print Labels.
