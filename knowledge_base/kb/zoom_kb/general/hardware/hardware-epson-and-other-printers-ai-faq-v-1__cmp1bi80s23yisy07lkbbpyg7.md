Hardware — Epson And Other Printers — FAQ
Q: How do I set up a supported Epson receipt printer over USB?

A: Download and install the Epson Advanced Printer Driver from Epson's official support site. Connect the printer by USB and power it on. Wait for Windows to finish creating the printer queue. Open Settings > Bluetooth & devices > Printers & scanners, set the Epson queue as the Windows default printer/default device, and print a Windows test page. Open Nova Wave and print a receipt test. If Windows never creates the queue or the test page fails, reinstall the driver or call Nova support.

Q: How do I set up an Epson receipt printer over Ethernet?

A: Connect the printer to power and Ethernet. Install the Epson driver and add the printer with a standard TCP/IP port, setting the IP address to Static (not DHCP). Find the correct driver for your printer model on Epson's official Support site. Once installed, set the Epson queue as the Windows default printer/default device and print a Windows test page. Run a sale or receipt reprint in Nova Wave to test. The IP must be static — if the printer stops working later, compare the installed queue against the printer's current IP and update the queue.

Q: My Epson printer queue won't print. What's wrong?

A: If Windows never creates the queue, or the Windows test page fails, reinstall the Epson Advanced Printer Driver. Make sure the driver matches your printer model — the correct driver for your model is listed on Epson's official Support site. If reinstalling doesn't fix it, call Nova support.

Q: How do I set up a Rongta receipt printer in Nova Wave?

A: Make sure the printer has power and the status light is solid. Reconnect the USB or Ethernet cable firmly. Install or update the correct printer driver. Confirm Windows shows the printer online, set it as the Windows default printer/default device, then run a test receipt in Nova Wave. If Windows cannot see the printer after the driver and cable checks, call Nova support.

Q: How do I set up a Citizen CS310 or CT-S310II receipt printer?

A: Confirm the printer has power and paper loaded, then connect it by USB or Ethernet. Install the Citizen CS310 / CT-S310II driver package from Nova at https://drive.google.com/file/d/1U4R6so1VTMh6_t2Is6PcR7rr66HTvVXE/view?usp=drive_link. If that package is unavailable, use Citizen's official CT-S310II driver page at https://www.citizen-systems.com/us/support/drivers-and-tools/CT-S310II?cHash=26228562b2a749988a99b12966ab28fa. Confirm Windows shows the printer online, set it as the Windows default printer/default device, print a Windows test page, then run a receipt test in Nova Wave. If Windows cannot create a working queue after the driver install, call Nova support.

Q: Why isn't my Rongta printer printing?

A: Start with the basics — power, status light, cable. Install or update the Rongta driver, confirm Windows shows the printer online, set it as the Windows default printer/default device, then run a test receipt in Nova Wave. If Windows still cannot see it after driver and cable checks, call Nova support.

Q: Which driver should I use for an off-brand receipt printer like Xprinter or Zonerich?

A: First confirm the exact brand and model. For off-brand thermal receipt printers such as Xprinter, Zonerich, and similar models, Nova documents a general-use driver at https://drive.google.com/file/d/1saYa4j8YCOEVcGAluTrhD8O5xcrZu0CW/view?usp=drive_link and a Generic POS thermal printer driver 4.57 at https://drive.google.com/file/d/10hyiXFa9qP32LBTX07nTsgNjQz8QSRlj/view?usp=drive_link. Install the driver, confirm Windows creates an online printer queue, set it as the Windows default printer/default device, print a Windows test page, then test a receipt in Nova Wave. If the driver does not create a working queue, call Nova support.

Q: Where do I download the Epson printer driver?

A: The Epson Advanced Printer Driver and model-specific drivers are on Epson's official Support site: https://epson.com/Support/sl/s?lang=en. Look up your exact model (TM-T20, TM-T88IV, TM-T88V / M244A, TM-T82II, or whatever you have) to find the right driver. Nova also documents these version-specific packages: Epson Advanced Printer Driver v4 at https://drive.google.com/file/d/1ZdEFo7kWAULG9k9btWoih8uFUhE6ANnQ/view?usp=drive_link, TM-T88V / M244A APD v5.07 at https://drive.google.com/file/d/1ZwBZa18EI-qbj1eDFtH1pzBcbtI6ugrg/view?usp=drive_link, TM-T82II APD v5.10 at https://drive.google.com/file/d/1vUTTiFUrdYb7EK6vBYxK7VXkfP0eYLi-/view?usp=drive_link, and TM-T20 APD v5.07 at https://drive.google.com/file/d/1pIvU6BBWepKASAXpA5uCHC8wIakouyHL/view?usp=drive_link. If you're not sure which driver to grab, call Nova support and an agent can verify before installing.

Q: My Epson printer stopped working after the network changed. What now?

A: The IP address probably changed when the printer reconnected to the network. Compare the installed Windows queue against the printer's current IP address and update the queue if the IP changed. The IP address should be set to static to prevent this — if it's currently on DHCP, switch it to static in the printer's network settings.
