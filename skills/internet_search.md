# Internet Search

Use public internet search only for public facts, current documentation, vendor pages, public changelogs, pricing pages, public legal/regulatory references, and other information that is safe to send outside the company.

If web/search tools are available in the Codex CLI session, use them for current or unstable information and cite the sources you relied on. Prefer official documentation, vendor docs, primary-source records, and reputable public sources.

If browser-only research is needed, use the configured Chrome/browser tools when available. Keep searches narrow and do not enter credentials, customer identifiers, internal ticket details, private account data, source code, API keys, database values, or Slack content into a public website.

The Slack bridge also supports `!search <query>` for public web lookups. Use that only for non-sensitive public questions.
